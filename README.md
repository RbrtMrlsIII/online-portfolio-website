# Roberto Cabalse Morales III · Portfolio

Cinematic single-page portfolio for Roberto Cabalse Morales III.

## Included
- Single-page responsive portfolio
- Glassmorphism UI direction
- Live video background architecture
- Supplied portrait as the hero asset
- EN / FIL language switcher
- Motion toggle and reduced-motion support
- Cursor-responsive 3D card tilt
- Responsive project, about, lab, and contact sections

## Video credit
Background video: [Beautiful coral reef with exotic reef fish](https://mixkit.co/free-stock-video/beautiful-coral-reef-with-exotic-reef-fish-44868/) by Mixkit.

## Run locally
Open `index.html` directly in a modern browser, or serve the folder with any static web server.

## Asset policy
This project intentionally contains no stock imagery or icon packs beyond the accepted Mixkit video (with credit) and the supplied portrait.

## Project governance

Read `product-law.md`, `product-vision.md`, `plan.md`, `validation.md`, `endorsement.md`, and `skill.md` before changing the product. Each phase has an explicit output contract, validation evidence, and continuation gate.

**Note:** Current design tokens are temporary defaults. The visual system is still open for change.

## Handoff rule

The Git repository (`main` branch) is the canonical source of truth. Every completed phase is committed and recorded in `validation.md` + `endorsement.md`.
