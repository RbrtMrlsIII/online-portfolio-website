# Product Law

This is the highest-level rule set for Roberto Cabalse Morales III's portfolio. The portfolio is treated as a product, not a collection of pages.

1. Product before feature. Every feature must serve the portfolio's purpose.
2. Experience before decoration. Visual effects must improve communication or interaction.
3. Responsive by law. Desktop, tablet, and mobile are first-class experiences.
4. Performance is a feature. Rich visuals must not create unacceptable loading or interaction cost.
5. Accessibility is not optional. Semantic structure, readable contrast, keyboard access, touch targets, and reduced motion remain required.
6. Progressive enhancement. WebGL, video, meshes, shaders, and advanced effects must enhance a usable DOM experience.
7. One visual language. Typography, spacing, glass material, lighting, motion, controls, and depth must remain coherent.
8. Content remains sovereign. The interface serves Roberto, not the other way around.
9. No unverified completion. A written implementation is not a completed phase without validation and endorsement.
10. No silent regressions. Material changes to an endorsed phase trigger re-validation.
11. Self-contained project. The complete portfolio must remain reproducible from the repository.
12. Every phase leaves the product healthier, clearer, and more maintainable.
13. Rule of restraint. When two solutions achieve the same goal, prefer the simpler one unless added complexity creates a measurable experience benefit.
